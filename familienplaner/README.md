# Familienplaner für Tessera

> Zeigt anstehende Termine aus mehreren Familienkalendern farblich sortiert auf einer Kachel an.

## Einrichtung

1. Kopiere den Ordner `familienplaner` nach `/config/tessera-plugins/familienplaner/` oder binde das Repository über **Add with a link** ein.
2. Trage unter den Kachel-Optionen deine Kalender-Entitäten kommasepariert ein (z. B. `calendar.anna, calendar.max, calendar.familie`).
3. Optional kannst du passende Anzeigenamen (`Anna, Max, Familie`) und Hex-Farben (`#3B82F6, #10B981, #F59E0B`) hinterlegen.
